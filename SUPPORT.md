# ChartUp Volume Booster Support

The official support channel is [`@chartup_support`](https://t.me/chartup_support).

## Prepare Your Request

To reduce unnecessary follow-up, provide:

- The official bot used
- Network and venue
- Contract address
- Order or task identifier
- Approximate start time
- Transaction hashes when relevant
- A short description of expected and observed behavior

Redact payment details and device information that are not needed to understand the issue.

## Do Not Send Credentials

Support does not need a private key, seed phrase, Telegram login code, or exchange password. If anyone requests one of these items, stop the conversation and verify the account through an official ChartUp channel.

## GitHub Issues

Repository issues should be limited to broken links, unclear documentation, incorrect public product information, or repository accessibility problems. Billing, active orders, and private account matters belong in the official Telegram support channel.
