# Contributing to the ChartUp Volume Booster Repository

Contributions should improve the accuracy, safety, or readability of this information repository. Product feature requests and order support requests should be sent to the official ChartUp support channel instead.

## Useful Contributions

- Correcting a broken official link
- Clarifying a network or feature description
- Improving accessibility or formatting
- Reporting outdated public information
- Fixing spelling and grammar

## Requirements

Every factual product change should cite a current ChartUp-controlled source. Do not add performance rankings, financial claims, unsupported integration claims, user statistics, or instructions that conflict with the current Terms & Conditions.

## Pull Requests

Keep each pull request focused. Explain what changed, why it changed, and which official source supports the correction. Confirm that local Markdown links still resolve before submitting.

By contributing, you confirm that you have the right to submit the material and that it does not expose private credentials or user information.
